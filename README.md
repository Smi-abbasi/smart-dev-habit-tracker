# Smart Dev Habit & Task Tracker

A clean and responsive React application designed to help developers build consistent habits, manage daily tasks, track focus time, and monitor productivity progress.

## Overview

**Smart Dev Habit & Task Tracker** provides a simple workspace for managing personal development activities such as coding, learning, reading, career work, exercise, health, and more.

The application focuses on keeping productivity tracking simple while providing useful statistics and visual feedback.

## Features

- 📊 **Real-time Productivity Overview**
  - Completion percentage
  - Total target focus minutes
  - Automatically calculated statistics

- ➕ **Add Habits & Tasks**
  - Add a custom title
  - Set target focus time
  - Select a category

- 📝 **Habit & Task Management**
  - View all habits and tasks
  - Mark tasks as completed or pending
  - Delete tasks when no longer needed

- 🔥 **Consistency Streaks**
  - Track consecutive progress with streak values
  - Visual streak indicators

- 🏷️ **Category-based Styling**
  - Coding
  - Learning
  - Reading
  - Career
  - Exercise
  - Health
  - Quran

- 📱 **Responsive Design**
  - Works across desktop, tablet, and mobile screen sizes
  - Clean card-based interface

- ⚡ **Client-side Application**
  - No backend required
  - React state manages application data

## Tech Stack

- **React**
- **JavaScript (ES6+)**
- **Tailwind CSS**
- **Vite**
- **HTML5**

## React Concepts Used

This project was also built as a practical exercise in core React concepts, including:

- Functional Components
- `useState`
- Props
- Passing arrays and objects through props
- Callback functions between components
- Rendering lists with `.map()`
- Conditional rendering
- Updating array state
- Event handling
- Derived statistics using `filter()` and `reduce()`
- Component-based architecture
